# Simulacro DPL · UT1

Test interactivo para preparar el examen de **Despliegue de Aplicaciones Web** (2.º CFGS DAW).

**300 preguntas** teórico-prácticas sobre:

| Bloque | Contenido |
|---|---|
| UT1 | Arquitecturas web, HTTP, Nginx, Node.js, systemd, VM, Docker, nube, diagnóstico y seguridad |
| Práctica 1 | Telnet, SSH y Wireshark |
| Práctica 2 | HTTP, HTTPS, TLS y Nginx |
| Modelo TCP/IP | El viaje de un paquete: encapsulación, ARP, MAC, IP, puertos |
| Firma digital | Cifrado simétrico/asimétrico, hash, certificados, FNMT, AutoFirma, eIDAS |

## Puntuación

Igual que el examen: **+1** acierto · **−⅓** fallo (3 fallos restan 1) · **0** en blanco.

## Modos

- **Corrección al momento**: te dice si está bien o mal y la explicación tras cada pregunta.
- **Simulacro de examen**: corrección al final, como el real.
- **Repasar fallos**: vuelve a preguntarte lo que has fallado (se guarda en tu navegador).

## Uso

Abre `index.html` en el navegador. No necesita instalación ni servidor: es una única página HTML.
